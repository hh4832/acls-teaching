# 第 5 章 重要危急心電圖判讀

ACLS 精華〈第 5 章 重要危急心電圖判讀〉（黃獻皋、顏湧章）教學投影片，41 頁。本章只教**心電圖辨認**；心搏過速／過緩的處置在專門課程。

**線上播放：** https://hh4832.github.io/acls-teaching/ch05-ecg/

## 特色

- **心電圖全部是動畫**：以 `../shared/ecg.js` 合成 25 種心律，像監視器一樣由左往右掃描；25 mm/s、10 mm/mV，可以直接數格子。只有目前這一頁的心電圖會動，列印時自動輸出靜態圖。
- **隨機監視器**：講師按「下一題」隨機換心律，學員搶答，再按「揭曉答案」。
- 猜猜看：6 題動態心電圖，點擊揭曉（A 全部揭曉）。

## 架構

- 一｜基礎：節律點、心電圖紙、間期與 QTc、命名、判讀四步驟
- 二｜心搏過速 Tachycardia：**心搏過速分類樹**（QRS 寬窄 → 規則 / P 波）→ VF、VT、TdP、寬 QRS 有 P、ST／AT、MAT、AFL、PSVT、AF
- 三｜心搏過緩 Bradycardia：**心搏過緩分類樹**（有無 QRS → 寬窄 → P 波 → PR 與掉拍）→ Asystole、IVR、三度（寬）vs SB 併 BBB、交界心律、SB、一度、二度 I／II、三度（窄）
- 四｜其他：AIVR、節律器心律
- 五｜測驗：猜猜看 6 題、隨機監視器；教材 vs 現行共識、Take-home

## 心電圖顯示

`ecg.js` 會依每種心律的振幅自動置中；若畫布高度放不下 10 mm/mV，會自動降低增益並在右下角標示（例如 `7.8 mm/mV`），波形不會被上下裁切。
