## 架構

評估（不穩定 vs 有症狀、心搏過緩是原因還是結果、五個危險徵候、潛在原因、阻斷位置與 atropine 反應）→ 流程（圖 7-1 重繪、劑量表）→ 治療（atropine、經皮節律器操作、dopamine / epinephrine、TVP、特殊情況）→ 小站練習（4 個情境題、決策監視器、教材 vs 2025、重點回顧）。

心律辨識在第 5 章，本章只講處置。
